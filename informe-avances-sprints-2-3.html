Módulo I · Gestión y Geozonificación

Sprint 2: Lógica Habitacional

El Sprint 2 se centró en la transición del sistema hacia un modelo operativo capaz de gestionar la oferta y demanda de vivienda en la ciudad de Pamplona. Se implementó el ciclo de vida completo de las publicaciones (CRUD) y la infraestructura geoespacial necesaria para garantizar la seguridad de los estudiantes.

1.1 Diagrama de Casos de Uso (Core)

Figura 1. Modelo de interacciones para la gestión de vivienda y mapas de seguridad.

1.2 Integración GIS (Leaflet + GeoJSON)

Se ha integrado la librería React-Leaflet para representar cartográficamente los sectores de Pamplona. La base de datos SQLite almacena los polígonos de los barrios en formato GeoJSON, permitiendo:

  • Zonificación Dinámica: Representación de niveles de riesgo (Verde, Amarillo, Rojo) basada en datos históricos de seguridad.
  • Geolocalización: Uso de useMapEvents para que el usuario asigne la ubicación exacta de su inmueble mediante un marcador.

1.3 Algoritmo de Coincidencias (Version 1.0)

El motor de matching básico calcula un Afinity Score comparando atributos categóricos de convivencia. El cálculo se realiza mediante una intersección de conjuntos de hábitos (Fumar, Mascotas, Ruido, Horarios) con una complejidad temporal de O(N).

Módulo II · Administración y Refinamiento

Sprint 3: Perfiles y Gobernanza

El Sprint 3 se enfocó en cerrar el ciclo de confianza del sistema mediante herramientas administrativas y la preparación para análisis de datos avanzado. Se implementó el dashboard de control y se integró la infraestructura base para futuros servicios de Inteligencia Artificial.

2.1 Diagrama de Secuencia: Verificación de Usuario

Figura 2. Flujo de verificación manual de usuarios por parte del rol administrador.

2.2 Integración de Infraestructura Gemini AI

A diferencia de una implementación puramente basada en reglas, en el Sprint 3 se ha integrado la arquitectura de Google Generative AI (SDK @google/genai) como base para el procesamiento de lenguaje natural.

Avance de Integración:

Se ha configurado el "scaffolding" necesario en vite.config.ts y las variables de entorno para consumir la API de Gemini. Esto permite que el sistema ya cuente con la capacidad técnica de:

  • Analizar descripciones de viviendas para extraer reglas implícitas.
  • Generar resúmenes inteligentes de perfiles para el matching.
  • Validar la coherencia de los comentarios y ratings mediante modelos de lenguaje.

2.3 Gobernanza y Administración

Se implementó la ruta /admin protegida por privilegios de correo institucional administrativo. Desde este panel se gestiona la lista completa de usuarios y se otorga el "check" de verificación, elemento vital para la reputación de la plataforma.
